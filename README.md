#### Projects

**[MergerIQ](https://mergeriq.launchdream.com/)** · M&A deal screening\
Estimates how likely a deal is to close from early signals. It runs a random forest trained on ~98 hand-picked deals (2012–2024, 11 sectors) with a 0.82 held-out AUC, and uses the Claude API for the analysis layer. Next, I'm turning it into a copilot that pulls deal terms straight out of SEC filings.

**[AlphaKnaut](https://alphaknaut.vercel.app)** · AI portfolio optimization\
My first build, made in about six weeks while learning to code. It covers the Magnificent Seven, pulls from four financial data APIs, and uses Claude to reason over the data.

**Zoneium CRM** · CRM for a working team\
Built so everyone on the team can see who has already been in contact with a prospect. It tracks organizations and agencies, the deal pipeline, next-step tasks and funding. Built with React and Supabase, deployed on Cloudflare Pages.
